# プロジェクト概要・ロードマップ

## 1. 背景

**Bisan（ビサン）** は、東京・十条で2011年に開業したパレスチナ料理店。
シェフ＝オーナーのスドゥキ・マンスール氏がパレスチナ本国から食材・スパイスを取り寄せ、
本格的なパレスチナ家庭料理を提供している。店名は、シェフの故郷でもある古都
**ビサン（Bisan / Beit She'an）** に由来する。

現在は東京（十条・本店）に加え、京都店（2024年11月開業）、山梨店（宿泊施設）を展開。

本プロジェクトは、この Bisan が **オンラインで商品を販売するためのECサイト** を構築するもの。

## 2. ゴール

- パレスチナの食文化と Bisan の世界観を、オンラインでも体験できるECサイトを作る。
- まずは **クナーファ（冷凍）** の単一商品販売から小さく始め、運用しながら拡張する。
- 将来的にスパイス・食材・ギフトセットなど、商品ラインナップを広げられる土台を作る。
