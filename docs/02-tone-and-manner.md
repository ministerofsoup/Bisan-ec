# トーン&マナー定義（ドラフト v0.1）

> [`01-brand-research.md`](01-brand-research.md) の調査を基に、ECサイトのビジュアル/言語のトーン&マナーを定義する。
> **暫定ドラフト**。実際のロゴ・写真・配色を確認のうえ確定する。
> このトンマナは `design/mockups/` の静的HTMLに反映している。

## 1. ブランドの核（Brand Essence）

> **「日本にいながら、パレスチナの食卓と物語に出会う」**

4つのキーワード：

| キーワード | 意味 | ECでの表れ方 |
| --- | --- | --- |
| Authentic（真正） | 本場・本物のパレスチナ | 産地・製法のストーリーを丁寧に伝える |
| Warm（温かさ） | 家庭料理・もてなし | 手仕事感のある写真、語りかける文体 |
| Proud（誇り） | パレスチナ文化への誇り | 文化的モチーフを堂々と用いる |
| Respectful（敬意） | センシティブな文脈への配慮 | 過度な政治利用や軽い扱いを避ける |

## 2. カラーパレット

パレスチナ国旗の4色（黒・白・緑・赤）を起点に、食欲を喚起する暖色（蜂蜜・テラコッタ）を加える。
（数値は仮。実ブランドに合わせて調整可能）

### プライマリ

| 役割 | 名称 | HEX | 用途 |
| --- | --- | --- | --- |
| Primary（深緑） | Olive / Palestine Green | `#1E5631` | 主要なブランドカラー、ヘッダー、CTA縁取り |
| Ink（黒） | Olive Black | `#1A1A18` | テキスト、フッター |
| Base（生成り） | Warm Cream | `#F7F1E6` | 背景 |

### アクセント

| 役割 | 名称 | HEX | 用途 |
| --- | --- | --- | --- |
| Accent（蜂蜜金） | Kunafa Gold | `#D98A2B` | 価格・CTA・強調（クナーファの黄金色） |
| Accent2（赤） | Palestine Red | `#B23A2E` | セール/限定など差し色（多用しない） |
| Accent3（緑） | Pistachio | `#7BA05B` | サブ装飾（ピスタチオの緑） |

> 赤は国旗由来でブランドに不可欠だが、面で多用すると印象が強くなりすぎるため**差し色に留める**。
> メインは「深緑 × 生成り × 蜂蜜金」で構成し、温かく上質な印象に。

## 3. タイポグラフィ

日本語が主たる言語であることを前提に、**和文＋欧文＋（必要に応じ）アラビア文字**を想定。

| 用途 | 書体方針 | 候補（Webフォント） |
| --- | --- | --- |
| 見出し（和文） | 品位のある明朝で物語性を | Noto Serif JP / 游明朝 |
| 見出し（欧文） | クラシックなセリフ | Playfair Display / Cormorant |
| 本文（和文） | 可読性の高いゴシック | Noto Sans JP |
| 本文（欧文） | 中立的サンセリフ | Inter / Noto Sans |
| 装飾・アラビア語 | 文化的アクセント（任意） | Noto Naskh Arabic |

方針：
- **見出しはセリフ／明朝**で「物語・伝統・上質」を、**本文はサンセリフ**で可読性を担保。
- 行間はゆったり（line-height 1.7〜1.9）。余白を活かした落ち着いたレイアウト。

## 4. ビジュアル / 写真トーン

- **食べ物の写真が主役**。自然光・温かい色温度で、湯気や蜂蜜のツヤなど「できたて感」を強調。
- 手や布、木のテーブルなど**手仕事・家庭の温度**が伝わる小物を添える。
- 過度な加工は避け、素材の質感を活かす。
- 文化的モチーフ（刺繍＝タトリーズ tatreez、幾何学模様）は**さりげない装飾**として用いる。

## 5. ボイス&トーン（文章のトーン）

| 場面 | トーン | 例 |
| --- | --- | --- |
| ブランド紹介 | 物語的・誠実 | 「店名のBisanは、シェフの故郷である古都の名前です。」 |
| 商品説明 | 温かく具体的 | 「カダイフを香ばしく焼き上げ、蜂蜜のシロップをたっぷりと。」 |
| 操作・案内 | 丁寧でわかりやすい | 「冷凍便でお届けします。お召し上がり方は同梱のカードをご覧ください。」 |

- 一人称・語りかけは丁寧体（です・ます）。
- 誇張・煽りは避け、**事実とストーリーで魅力を伝える**。
- パレスチナという文脈は敬意をもって扱い、軽い消費や政治的断定は避ける。

## 6. UI コンポーネントの方針

- **ボタン（CTA）**：深緑地 or 蜂蜜金。角丸は控えめ（4〜6px）。十分な余白。
- **価格表示**：蜂蜜金 or 黒で明快に。冷凍・送料の注記を近くに添える。
- **余白**：詰め込まず、ゆとりある余白で「上質なお取り寄せ」の体験を。
- **モチーフ**：幾何学パターンの罫線やセクション区切りをアクセントに（多用しない）。

## 7. CSS 変数（実装の起点）

`design/mockups/assets/css/styles.css` の `:root` に下記を定義済み：

```css
:root {
  --color-primary: #1E5631;   /* Olive / Palestine Green */
  --color-ink:     #1A1A18;   /* Olive Black */
  --color-base:    #F7F1E6;   /* Warm Cream */
  --color-gold:    #D98A2B;   /* Kunafa Gold */
  --color-red:     #B23A2E;   /* Palestine Red */
  --color-pistachio:#7BA05B;  /* Pistachio */
}
```
