# 商品情報・要件：クナーファ（冷凍）

> 本ECの最初の商品。商品ページ／配送／表示の要件を整理する。
> 数値・仕様は**仮（要確定）**。Bisan の実際の商品仕様に置き換えること。

## 1. 商品とは

**クナーファ（Kunafa / كنافة）** は、パレスチナをはじめ中東で愛される伝統菓子。
カダイフ（細い糸状のペストリー）や生地でチーズ等を包み、焼き上げて砂糖シロップをかけ、
ピスタチオを散らす。**温かいうちに食べる、とろけるチーズと香ばしい生地**が魅力。

日本ではほとんど食べられない希少なスイーツであり、Bisan の魅力を象徴する一品。

## 2. 商品ページに載せたい要素

- 美しい商品写真（断面のチーズの伸び／黄金色の生地／ピスタチオ）
- 物語：クナーファとは何か、パレスチナでの位置づけ、Bisan のこだわり
- 内容量・サイズ・人数の目安
- 原材料・アレルゲン表示（小麦・乳 など）
- 賞味期限／保存方法（冷凍）
- **解凍・温め方ガイド**（食品ECで最重要。美味しく食べてもらうため）
- 配送方法（冷凍便）・送料・お届け目安
- 価格（＋送料の考え方）
- ギフト対応の有無（のし・メッセージ等／将来）
